# MedFlow 🏥

### MedFlow: An Intelligent Hospital Workflow and Patient Management Platform

MedFlow is a full-stack healthcare management platform designed to streamline hospital workflows and improve patient care.
It enables seamless interaction between **patients, doctors, and administrators** through a secure and scalable web application.

This project is being developed as a **major engineering project with a focus on real-world healthcare automation and intelligent systems**.

---

## 🚀 Features

### 👨‍⚕️ Doctor Panel

* View and manage appointments
* Access patient records
* Update diagnosis and prescriptions
* Manage availability

### 🧑‍💼 Admin Panel

* Manage doctors and patients
* Monitor system activity
* Handle appointment scheduling
* Manage healthcare resources

### 🧑‍🦱 Patient Panel

* Book appointments with doctors
* View medical history
* Access prescriptions
* Receive healthcare updates

## ⚙️ Installation

### 1️⃣ Clone the repository

```
git clone https://github.com/YOUR_GITHUB_USERNAME/MedFlow.git
cd MedFlow
```

### 2️⃣ Install frontend dependencies

```
cd frontend
npm install
```

### 3️⃣ Install backend dependencies

```
cd ../backend
npm install
```

### 4️⃣ Run the project

Backend:

```
npm run dev
```

Frontend:

```
npm start
```

---

## 🔐 Environment Variables

Create a `.env` file inside the backend folder.

Example:

```
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
